      Field notes

      The small print, in the small print font.

      Windows says it doesn't know me

      True. The build is unsigned, because a hobby desk does not buy certificates. Windows SmartScreen will say “unrecognised app”; choose More info, then Run anyway. Unzip first, run greytide.exe from the folder, and keep the folder together.

      Linux

      Unzip, then chmod +x greytide && ./greytide. It wants Vulkan or OpenGL 4.5 and a desktop; there is no server mode, because the horde does not need one.

      Playing in the browser

      It is the real game compiled to WebGL2, about 10 MB, and it runs a few times slower than the desktop build. A recent desktop Chrome, Edge, Firefox or Safari is best. Phones start it, and their battery will have opinions. It never leaves your browser: nothing is uploaded, nothing is tracked, and the horde is not sent anywhere.

      Why the build numbers look like that

      Each build is named dev- plus the first seven characters of the commit it was cut from. Builds are pre-releases on purpose: the list under “what changed tonight” is the pull requests merged since the previous build, so it is as honest as the pull request titles are. Commit links go to a private repository, so they only open for the people who work on it.

      Is this finished?

      No. The working title is a placeholder, the towers are a work in progress, some of the grunts are still being unboxed, and the soundtrack was generated by a computer that has never had a hobby. Painted minis are for the desk, and the horde gets what is left in the bag.
